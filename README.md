## Word Mixer

CLI script to practice vocabulary from markdown files. 

## Adding files

❗ Before adding files to data folder, see the format of example.md file ❗.

## Install

Option 1: Using pipx (recommended)
pipx install git+https://github.com/purebeach363/word_mixer.git
Option 2: Manual installation
git clone https://github.com/purebeach363/word_mixer.git
→ cd word_mixer
→ python -m venv .venv
→ source .venv/bin/activate
→ pip install .

## Run

wordmixer
